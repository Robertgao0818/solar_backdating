- **What it proves:** the "no wobble" goal — the student is bit-deterministic,
  so two passes over the same frames must produce byte-identical observations →
  identical `InstallDatePosterior` → identical `agree_key`.

  `chip_path` (no RNG; ISSUE-03/04 determinism tests already assert this).
- **Compute:** local GPU, 2× student scoring over one rep (~15.3k frames for
  rep1: L0 244 + L1 chips). Cheapest gate; piggybacks on the gate-2 re-scoring
  pass run twice.
- **Expected result:** 1.0 by construction — but it must be **demonstrated**

**The genuine gap — one new harness** (e.g. `scripts/validation/fidelity_gate.py`).
Two facts define the gap:

- `llm_endtoend_analyze.py` computes agree_key interval agreement **only on the
  raw `delivery.csv`** (the production `merge_three_layers` output), **not** on
  Phase-0-decoder output.
- `estimator_endtoend_decode.py` decodes each rep's scan_states through the
  adopted decoder **but extracts only `posterior.map_date[:4]` (year) and reports
  TVD** (line 294) — it **discards** `map_interval_start/end` and has **no
  agree_key path** (grep-confirmed: no `agree_key` / `AP_BOUND` token in it,
  `issue03_gates.py`, or `build_cohort_fractional_year_table.py`).

So the new harness must:
1. For a rep, walk `reference.csv` → per-anchor L0/L1 scan_states using the
   already-solved join keys (`LAYER_MAP`: `group_anchor_id`→L0,
   `target_anchor_id`→L1; L_census / AP-bound / undated = splice-through).
2. **Re-score each frame's `chip_path` with the student** and assemble a
   parallel `VintageObservation` sequence (student `pv_present`/`confidence`,
   same `capture_date`s) — this is the mirror of `scan_state_io.load_scan_observations`
   the student side lacks, and the only substantive new code.
3. Decode **both** teacher-obs and student-obs through the same registered
   decoder → `InstallDatePosterior`.
4. Map posterior → `agree_key` via `map_interval_start/end` + `p_undated`
   (adapter — the second small new piece).
5. Compute **student-vs-teacher** agreement **and** Gemini **rep-i-vs-rep-j**
   agreement (the re-derived ceiling), inventory-weighted headline + dated-only
   denominator alongside (D8). Reuse `llm_endtoend_analyze`'s `agg()` /
   weighting / `agree_key_raw`.

Everything except (2) the student re-scoring pass and (4) the posterior→agree_key
adapter is reuse. Ship the harness with unit tests on the adapter (posterior →
agree_key round-trip on synthetic posteriors covering UNDATED / AP_BOUND /
INTERVAL) and a rep-vs-rep smoke on a tiny fixture — do not put the offline
benchmark in CI (ISSUE-06 AC: reported in `docs/`, not asserted).

## Risks and the pre-registered tie-break rule

**R1 — the L-SAT-vs-floor falsification is decided in the noise (must pre-register
BEFORE writing the composite verdict).** Gate-3 held-out agreement is a dead heat:

- DINOv3-L-SAT **0.797101** @ 0.884615 cov vs DINOv2 floor **0.796813** @
  0.877622 cov (both n=858). **Δ decided-agreement = 0.000288 (0.029 pp)** on
  ~758 decided rows — about **0.2 rows**, i.e. ≈0.02 of one binomial SE
  (SE ≈ √(0.8·0.2/758) ≈ 1.45 pp). L-SAT's only edge is **+0.70 pp coverage**.
- Gate 1 is ≈1.0 for **both** backbones by construction, so it does not
  discriminate.
- **Pre-registered rule (lock before producing gate-2 numbers):**
  1. Declare gate-3 chip fidelity **EQUIVALENT** if `|Δ decided-agreement| < 1
     binomial SE (~1.4 pp)` — which it already is (0.029 pp). Under equivalence,
     the SAT/L bet is **falsified on gate 3**: a 22M natural-image floor matches
     the SAT-pretrained L encoder on chip fidelity.
  2. The SAT/L bet **survives overall only if** L-SAT's inventory-weighted
     **gate-2** (interval) student-vs-teacher agreement exceeds the floor's by
     **more than the Gemini rep↔rep ceiling's own pairwise spread** (the noise
     floor the ceiling itself establishes). If the gap is within that spread,
     the bet is **falsified** and the cheaper floor is the equivalent — report
     both, adopt the floor per the D-plan falsification logic.
  3. Coverage ties break to the **higher-coverage** backbone only when (1) and
     (2) are both equivalence — a tie-break, never a bet-survival signal.
  This rule is written here so the verdict cannot be back-fit to the numbers.

**R2 — the 14 pp calib-optimism lesson.** The calib-half agreement (0.939 /
0.9495, **in-sample**, 82 anchors) overstated the held-out report-half by ~14 pp.
Discipline for the gate: **calibrate/tune nothing on the cohort being measured** —
the band is already frozen from ISSUE-04/05; the gate reports **only** held-out
interval/chip agreement, and the verdict never quotes 0.939/0.9495 as a
generalization number.

**R3 — thin unusable-class recall (known weak spot).** Both students under-recall
the teacher's `unusable` class — from the report-half confusion matrices, the
student *decides* present/absent on many teacher-`unusable` frames (DINOv3:
40 present + 60 absent vs only 20 correctly `unusable` of 120; floor similar,
52 + 46 vs 19). A spuriously-*decided* frame can move a censoring bound, so this
can perturb gate-2 interval agreement more than gate-3 chip agreement suggests.
Report the interval agreement **split by whether the teacher flagged unusable
frames in the anchor's window**, so the weak spot is visible and not averaged
away.

**R4 — do not write into the ISSUE-21 run dir.** `llm_endtoend_storebacked_20260704/`
is owned by the concurrent ISSUE-21 session (its `analysis_issue21_5rep/` was
written 23:09). Read the banked reps; write slice-6 outputs to a fresh dir.
