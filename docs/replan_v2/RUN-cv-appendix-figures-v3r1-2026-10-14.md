## 3. F1：另外三种地块的三类计数

τ 是天数容差。三类规则对有日期、只知到普查日、混合这三种地块是同一套：登记滞后是区间终点不晚于验收日；一致是起点不晚于验收日加 τ，而且终点晚于验收日；矛盾是起点晚于验收日加 τ。混合地块的区间仍是 §B.3 的最早起点和最早终点，横跨有日期的多边形和只知到普查日的多边形。只知到普查日的地块，终点就是普查日 2025-01-31。这一批所有验收日都早于这一天，所以这种地块的登记滞后是 0。

左删失的地块没有起点。终点不晚于验收日就是登记滞后，否则是一致。它按定义不可能是矛盾。未定日和没有模型多边形的地块不进这三类。

审查按同一套规则给出了 τ = 90 的期望。本批算出来的数与期望相同，所以才组装。如果对不上，发布目录不会写出来。

## 4. F2：把观测柱拉开

观测最高的一档是 166 块。纵轴现在停在 1.3 倍这个高度，也就是 215.8 块。参考线在靠近 0 的两档升到轴外。这两档的参考户数从直方图 CSV 读出，四舍五入后是 1,089 和 1,159。图内写的是 “Reference reaches 1,089 and 1,159 in the two bins next to 0 (clipped).” 标题里的中位数用的是 Unicode 减号，写成 median −2.83。脚注在图内，图例在右上，没有压住柱子。横轴标题和脚注分开。

215.8 这个上限的意思是：读者能看清观测柱的形状，同时知道参考线在 0 附近被裁掉了。如果把轴放回参考线的全高，柱子又会被压成一条细带，中位数 −2.83 个月旁边那根很宽的观测分布就看不出来。如果把参考线删掉，又会丢掉“区间本身很窄，宽出来的是验收日和中点的差”这一点。裁轴并注明被裁的两档，是这两件事同时成立的画法。
