## B. SSEG 对比口径草案（待群里确认后冻结）

负责人 2026-10-13 认可了这个方向：相关性降为描述性指标，门槛改为"系统级单侧矛盾率"；矛盾案例**先用航拍裁定，裁定不了的再人工复核**。下面方括号里的数字是待商定的建议值。

### B.1 为什么不再用"相关性 > 0.7"当门槛

- **累计曲线几乎一定过线。** 两条只增不减的曲线，相关系数通常在 0.9 以上，分不出 3.1 和 3.5 的好坏。
- **月度新增数的相关，有一部分量的是登记流程。** 2022–23 年限电高峰让两条曲线一起上升；SSEG 的审批积压和集中补登记、卫星拍摄日期的不均匀，也都会改变相关系数，但都和屋顶上何时出现板子无关。
- **SSEG 的日期本身不准。** 直接拿它当正确答案求相关或求偏差，会把 SSEG 的误差全部算成模型误差。

如果忽略这几点，门槛要么形同虚设，要么在惩罚登记流程，起不到"判断模型够不够好"的作用。

### B.2 关键前提：SSEG 日期误差的方向

SSEG 的 commission date（并网验收日期，记作 C）**不会早于真实安装日期**：登记滞后和补登记只会让 C 变晚。所以 C 可以当作安装日期的**上界**，但不能当作点估计。下面的指标都建立在这个单侧关系上。少数例外（比如把申请日录成了验收日、坐标落错房子）由 B.6 的核验步骤识别出来。

### B.3 样本与匹配

- **SSEG 记录：** 只用状态为 commissioned 的记录。同一地块有多条记录时，取最早的 C。
- **空间匹配：** SSEG 坐标 → 市政地块（`ODP_SPLIT_4/MapServer/0`）→ 质心落在该地块内的普查多边形。
- **分析单位是地块。** 一个地块上有多个多边形时，地块的 L 取所有多边形中最早的 L。只要有一个阵列在 C 之前已经出现，就不算矛盾。左删失的多边形（2019 年前已有）视为 L 不存在，地块不可能矛盾。
- **主样本：** 地块上恰好一条 commissioned 记录，坐标落在地块内（不用缓冲区）。10 m 缓冲区匹配、多条记录的地块只进敏感性分析。
- **配对：** 3.1 和 3.5 在**同一批地块**上比较；任一模型缺结果的地块，两边都剔除，并报告剔除数。
- **时间范围：** C 早于普查日（2025-01-31）。C 早于 2019 年的地块单独列出，因为模型窗口从 2019 年开始，这些地块预期是左删失。

### B.4 记号与三种情况

模型给每个地块一个区间：L 为最后一次看到"没有板"的日期，U 为第一次看到"有板"的日期。容差 τ 主分析取 **90 天**（会议说的"90 天"放在这里），用来吸收卫星拍摄日期和 SSEG 录入的误差。

| 情况 | 条件 | 含义 |
|---|---|---|
| 登记滞后 | U ≤ C | 先看到板，后验收。是预期结果，不算错 |
| 一致 | L ≤ C + τ，且 U > C | 验收日落在区间内或附近 |
| **矛盾** | **L > C + τ** | 已经验收了，模型之后还说没有板。可能是模型漏看，也可能是 SSEG 或匹配出错，交给 B.6 判定 |

未定日（nonmonotonic、ambiguous）的地块不进这三类，但要单独报告比例。3.5 的"看不清"和"不能采纳"帧不能当作"无板"，区间只用可用帧来算。

### B.5 指标

1. **主指标：归因于模型的矛盾率** = 经 B.6 判为"模型错"的矛盾地块数 ÷ 主样本地块数。核验后仍未判定的案例，按两种极端各算一次，报告上下界（全算模型错、全不算模型错）。
2. **配套指标，必须和主指标一起报：** 区间宽度的中位数，以及有日期的比例。否则一个模型只要把区间拉宽，就能压低矛盾率。
3. **描述性指标，登记滞后：** 在 U ≤ C 的地块上，C − U 的中位数和四分位距。它不是准确度，但它估计的是"装好后多久才登记"，可以直接放进附录图 D6。
4. **描述性指标，相关性（附录图 D5）：** 用月度新增数（不用累计数）计算，同时算把 SSEG 往后错开 0–12 个月时的相关（交叉相关），报告最高的相关值和对应的错开月数。不作为门槛。
5. **敏感性分析：** τ 取 0、30、180 天；改用缓冲区匹配；把 census_bound 和左删失地块单独列出。

### B.6 矛盾案例的核验：先航拍，后人工

两个模型的矛盾地块取并集，每个"地块 × 日期"只判一次，两边共用判定结果。

**第一步：航拍裁定。** 可用的航拍年份点有市政 2020Jan、2021Mar、2022Jan（8 cm），Vexcel 2024（6.2 cm，每个点的拍摄日期可以查到），以及市政 2025Jan（5 cm，普查层）。

- **能用来裁定的航拍：** 拍摄日期 A 满足 C + [30] 天 < A ≤ L，也就是验收之后、模型最后一次说"没有板"之前拍的。市政航拍按标签月份的第一天计日期。
- **判读方法：** 在这张航拍上看该地块有没有板。看到板，判"模型错"（卫星帧漏看了）；没有板，判"SSEG 或匹配错"；看不清，转入第二步。
- **转入第二步的情况：** 没有满足条件的航拍（典型情形是 C 和 L 都落在 2022 年 2 月到 2024 年 2 月之间，那段时间只有 25 cm 的 NGI 影像）。
- **判读的人和盲法：** 由人工判读航拍，航拍比卫星清楚得多，判读快。另外随机混入约 [50] 个非矛盾地块作对照，判读者不知道哪些是矛盾案例，也不知道来自哪个模型。抽 [20%] 做双人判读，报告两人一致率。

**第二步：人工复核卫星帧。** 只处理第一步裁定不了的案例。给判读者看四张图：L 那天的卫星帧、C 之后最近的一帧、U 那天的卫星帧、普查航拍。判读者不知道模型版本，也不知道 SSEG 日期，只回答"L 那天屋顶上有没有板"。判读结果的分类方式与第一步相同。

**为什么先航拍。** 航拍和普查检测器用的是同类影像，判读最可靠，而且它与模型和 SSEG 都无关，是真正的第三方。卫星帧正是模型判断时看的那张图，用它人工复核，可能和模型犯同样的错，所以只留给航拍覆盖不到的案例。

### B.7 3.1 对 3.5 与停止规则

- **比较方式：** 在同一批地块上比较两个模型的主指标差异，置信区间用按 H3-9 hexagon 分组的 bootstrap（有放回重复抽样）估计，重复 [2,000] 次。
- **停止规则：** 满足以下全部条件就停止升级：
  - (a) 新版本"归因于模型的矛盾率"的**上界** ≤ [10%]；
  - (b) 新版本相对旧版本的改进不显著（置信区间包含 0），或者改进小于 [2 个百分点]；
  - (c) 区间宽度中位数和未定日比例没有变差超过 [20%]。
- **样本量：** 矛盾率在 10% 左右时，要把 95% 置信区间控制在 ±3.5 个百分点以内，大约需要 300 个匹配地块。拿到 SSEG 后，第一步是数清十格（1,114 个锚点）里能匹配上多少个地块；不够 300 个，就需要决定要不要把 3.5 扩到更多格子。

### B.8 执行顺序

1. 本节在群里确认，方括号里的数值定下来后冻结，之后不再改口径。
2. 拿到 SSEG 后，按 B.3 匹配，数十格内主样本的地块数，决定是否需要扩大样本。
3. 计算三种情况和 B.5 的各项指标。这一步只用模型输出和 SSEG，不看图。
4. 对矛盾地块按 B.6 先做航拍裁定，再做人工复核。
5. 算出主指标的上下界，按 B.7 判定是否停止升级，写进 RUN 文档。

  - **A 的补充（推荐做）**：用上面五期航拍在年份点上检查"有没有板"，作为卫星回溯的独立检验，同时用作图 D2 Panel A 的逐年图。抽样检查就够，不需要全城检测。
