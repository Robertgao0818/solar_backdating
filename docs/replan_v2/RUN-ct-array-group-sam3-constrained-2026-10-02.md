## 决策与意义

文字 SAM3 可以作为**已有对象的边界精修器**继续研究。受限方案在 07 收紧真板轮廓而不接纳下方独立疑似集热器；完整视野的 02 能去掉明显屋顶空隙，03 的部分碎片边界也更规则。这支持将身份、边界、归组分开处理；忽略这种分工，就容易把轮廓锐利误解成物体身份正确或数量误报减少。

**尚不能锁定全局收紧参数。** 02 双方共同偏好严格收紧，但 Codex 对严格／局部方案均保留反光板像素可能被削掉的疑虑；03 双方共同偏好局部外扩 0.5 米，Gemini 指出严格方案可能漏掉一个短块。这意味着参数需要按对象回退及保留未决；忽略这一点可能用更漂亮的边界换掉真板覆盖。

**当前库存中找到一个共同非光伏候选 `broad_07`：屋顶投影。** 其库存 FID 为 15619，网格 CPT2119，原预测面积约 6.46 平方米；Codex 与 Gemini 分别判断它缺少板框结构、与邻屋投影方向一致。它证明“当前库存残留身份误报”值得继续筛查，但不是独立真值，更不能从这一个定向选样估计全城数量 FP（把不存在的安装算成一处）。忽略后两项限制会高估自动筛查收益。

暂不推进 60 例全面接纳方案，不将共识候选直接写回库存。保留严格与局部候选、身份分歧和可追溯原始输出；首轮 5 对归组建议仍为候选，本轮未应用。碎片归组必须遵循负责人确定的“明显同片安装的阵列群”，不能从 SAM3 的单板分割数生成安装数。
