这一批只有一张图，D6。它比较两件事：模型给一个地块的安装区间，和这个地块上那一条已投运 SSEG 的验收日。SSEG 是市政的小规模嵌入式发电登记。验收日记作 C，它是安装日期的上界，因为登记滞后只会让 C 变晚，不会让它变早。图上的 Δ 是区间中点减去 C，单位是月。负的 Δ 表示中点比验收日更早。

这张图不是模型得分。矛盾地块没有拿航拍逐张看过，任务清单 §B.6 的那一步没有做，所以这里不能报“归因于模型的矛盾率”。3.1 和 3.5 的门槛比较也没有做。

τ（tau）是放在验收日上的天数容差，用来吸收卫星拍摄日和录入日对不齐。主分析是 90 天。它不是测量精度。

## 3. 主样本

主样本是：地块上恰好一条已投运记录，点严格落在地块内，而且 C 早于 2024-10-31。这是普查日 2025-01-31 再往前三个月。这一批是 5,081 块。

这 5,081 块里，C 没有早于规则却被另外丢掉的。整份登记的验收日从 2011-11-26 到 2024-07-02，没有一条晚于或等于 2024-10-31，也没有一条晚于或等于普查日。所以“早于 2024-10-31”这条规则在这批数据上没有删掉任何人。规则仍然写在代码里。如果以后的登记摘录包含 2024 年秋天的验收，去掉这条规则，样本就会和这一批不可比。

| 类别 | 地块数 | 进不进直方图 |
|---|---:|---|
| 有日期 | 2,755 | 进。这是图上的 N |
| 左删失 | 1,071 | 不进。2019 年前已经有板，区间没有起点，不可能构成矛盾 |
| 混合 | 643 | 不进。同一地块上既有有日期的多边形，也有只知到普查日为止的多边形 |
| 没有模型多边形 | 342 | 不进。验收点在地块内，但没有普查质心落进来 |
| 只知到普查日 | 241 | 不进。只报数量 |
| 未定日 | 29 | 不进三类，单独报。占主样本 29 / 5,081 |

有日期的比例是 2,755 / 5,081 = 0.5422。如果分母改成“主样本里至少有一个模型多边形”的 4,739 块，比例是 0.5813。两个数都要留着。前一个会把“地块上没有检出多边形”算进“模型没有给出日期”。后一个才是日期规则本身盖住了多少块。任务清单要求区间宽度和有日期的比例跟矛盾计数一起看：模型只要少给日期，或者把区间拉宽，矛盾计数就会下降。这里的中位区间宽度是 32 天，比 90 天的容差更窄，所以这一批的矛盾计数不是被拉宽的区间压下去的。

地块的区间取这块地上有日期多边形里最早的起点和最早的终点。中点是这个合成区间的日历中点，不是某一块板自己的中点。同一地块上有多块板时，只要有一块在验收前已经出现，这块地就不算矛盾。这个规则用的是最早的起点。

左删失的多边形会使整块地没有起点。这样一块地不可能被算成矛盾。如果把这种地放进直方图，就会把“2019 年以前已经有板”画成一个日期。

混合的 643 块没有套用三类规则。全市 6,010 块混合地的合成区间都满足终点不早于起点，所以没有触发“停下来、不另写规则”的那一条。如果把混合地的普查日终点拿来算 Δ，中点会被普查日拽晚，图就不再只描述有日期的系统。

## 4. 直方图上的数字

一个月按 365.2425 / 12 = 30.436875 天计。Δ 的月数是整数天数除以这个长度。计划只说“月”，没有指定一个月有几天。这个除数写在常量模块里，也写进了清单。分位数用 NumPy 的 linear 方法。四分位距是第 75 百分位减第 25 百分位。

在 2,755 块有日期的地上：

| 量 | 值 | 怎么读 |
|---|---|---|
| 均值 | −1.93 月 | 原始值 −1.933966。中点平均比验收日早不到两个月 |
| 中位数 | −2.83 月 | 原始值 −2.825520。一半地块的中点比验收日早至少大约三个月 |
| 四分位距 | 11.20 月 | 第 25 百分位 −8.77 月，第 75 百分位 2.43 月 |
| 全距 | −61.21 到 104.48 月 | 窗口外的尾巴还在这些汇总里 |
| \|Δ\| ≤ 6 个月 | 1,311 / 2,755 | 份额 0.4759 |
| \|Δ\| ≤ 12 个月 | 2,025 / 2,755 | 份额 0.7350 |
| C 落在闭区间 [L, U] 内 | 390 / 2,755 | 份额 0.1416。这和下面的“一致”不是同一件事 |
| 区间宽度中位数 | 32 天 | 第 25 百分位 30 天，第 75 百分位 91 天，四分位距 61 天 |

图上只画 −36 到 36 个月。窗口以下 38 块，窗口以上 48 块。均值、中位数和份额都含这 86 块。参考分布的质量全部落在窗口内，窗口外的参考户数是 0。最长的那些区间，半宽也到不了 36 个月。

黑色参考线的算法：对每一对，把从 L 到 U 的每一个日历日（含两端）看成同样可能的验收日，计算中点减这一天，再累加到同一组月档里。这是精确的混合分布，不是随机抽样。含两端的天数比“终点减起点”多一天。报告的区间宽度用的是终点减起点，32 天对应 33 个可抽取的日历日。两套计数故意不一样，分别对应“区间有多长”和“均匀分布抽的是哪一天”。

含 0 的那一档，参考线期望 1,158.55 块，观测只有 121 块。观测最高的一档是 166 块。参考线在 0 附近成一根针，是因为中位区间只有 32 天：假如验收日真的落在各自的区间里，Δ 几乎都会挤在 0 前后一个月内。观测直方图比这根针宽得多，而且重心在 0 的左边。

这根针对读图是必要的。如果只看中位数 −2.83 个月，会觉得两边差不多。参考线说明，区间本身很窄，宽出来的是验收日和中点之间的差，而且差的方向与“先看到板、后验收”一致。忽略这根线，就会把登记滞后读成一个很小的平均偏差。

在 U ≤ C 的 1,566 块地上，从第一次看到有板到验收日的滞后，中位数是 150.5 天（4.94 个月），四分位距是 284.75 天（第 25 百分位 74 天，第 75 百分位 358.75 天）。这 1,566 块就是 τ = 90 时的“登记滞后”类，两个计数对得上。这个滞后估计的是装好之后多久才登记。它不是准确程度。如果把它当成模型误差，登记流程慢的月份会被算成模型错了。

## 5. 三类计数和敏感性

只在有日期的地上分类。登记滞后：U ≤ C。一致：L ≤ C + τ 且 U > C。矛盾：L > C + τ。三类互斥，并且加总等于 2,755。左删失、普查日上界、混合、未定日和没有模型多边形的地块不进这三类。

| τ（天） | 登记滞后 | 一致 | 矛盾 |
|---|---:|---:|---:|
| 0 | 1,566 | 384 | 805 |
| 30 | 1,566 | 463 | 726 |
| 90（主分析） | 1,566 | 570 | 619 |
| 180 | 1,566 | 712 | 477 |

登记滞后不随 τ 变化，因为它只看 U 和 C。τ 变大时，一些矛盾地块会变成一致。放到 180 天，矛盾还剩 477 块。619 块里的大多数并不是刚好卡在 90 天边上。中位区间宽度 32 天又短于 90 天，所以这个矛盾计数也不是“容差比区间窄，所以被容差切出来的”。

619 / 2,755 仍然只是描述。矛盾可以是模型漏看，也可以是 SSEG 坐标或匹配错了。航拍复核没有做。如果把 619 / 2,755 写成模型错误率，就会跳过计划里规定的复核，也会把登记表当成正确答案。

10 米缓冲是敏感性，单位是米，投影是 EPSG:32734。点已经在地块内的，保持 Phase 0 的分配。点在外面、而且 10 米内只靠近一块地的，才会新配上。10 米内靠近两块或更多的，不选，标成含糊。这一批里，带坐标却落在所有地块外的已投运点是 0 个，所以新配上 0 块，含糊 0 个。缓冲样本的三类计数与主样本相同，`fig_D6_classes.csv` 里的 `buffer_dated` 就是这些相同的数。没有坐标的 312 条不能靠缓冲救回来，也没有去读三位小数的经纬度。旧的约 0.00012 度诊断同样是 0，那个诊断不是这一批用的规则。米制规则在合成多边形上测试过：距两块地都正好 10 米的点不会被配上。

多条已投运记录的地块有 27 块、65 条记录。它们只用最早的 C，而且这 27 块的最早 C 都早于 2024-10-31。其中 12 块有日期。τ = 90 时，登记滞后 6、一致 1、矛盾 5。这 12 块不进直方图。如果把多条记录并进主样本，一块地上后登记的系统会改掉最早那一条的比较。

## 6. 2019 年以前的验收

模型窗口从 2019-01 开始，所以 C 早于 2019-01-01 的地块要单独列出。主样本里有 263 块。其中 201 块是左删失，这是窗口从 2019 年开始时会预期看到的情况。另外 13 块是有日期的，它们留在直方图里。τ = 90 时，这 13 块里 12 块是矛盾、1 块是一致。τ = 0 时，13 块全是矛盾。那 1 块一致的，起点晚于验收日，但没有晚过 90 天。

这 13 块没有从主样本里剔除。计划要求把它们列出来，是因为模型看不到 2019 年以前，而不是因为要把它们藏起来。如果删掉，直方图会少掉一批“验收明显早于模型窗口、但模型却给了 2019 年后区间”的地块。

有日期的 2,755 块里，多边形全来自 27 波的是 2,101 块，全来自 Top-52 的是 641 块，两套多边形都有的是 13 块。Top-52 没有逐次成像序列，那是 D5 成像条的限制。D6 用的是已经发表的区间，所以 Top-52 留在图里。去掉它们，这张图就不再是全城的比较。
