A 两仓库研究画像

ZAsolar

屋顶 PV 高分普查

核心问题：南非城市高分辨率航拍中稳定检出住宅屋顶光伏，产出可用于经济/政策分析的网格聚合装机清单。

方法：Mask R-CNN（ResNet-50+FPN）→ SAM 2.1 精修 → solar_cls 压制热水器/look-alike FP。主指标为 grid 级 inventory（σ_Bw、RMSE），polygon F1 仅诊断。

数据：Cape Town ~8 cm；Johannesburg Vexcel ~6.7 cm。CT ~11.2 万 installations；JHB FP-cut ~4.1 万 dets。

solar_backdating

Location-conditioned 定年

核心问题：给定 ZAsolar footprint（锚点），从历史影像 vintage 推断出现年份/区间。

方法：锚点缓冲 chip → present/absent/unusable → 单调断点。GEHI Time Machine 为 sole 影像源；Gemini review；v2 规划 DINOv3-L-SAT student（fidelity-gated）。

进度：JHB 92.7% 点估计 + 2.5% 下界（~95.1% 有标签）。v2：P0–P4 优化程序已立项（2026-07-03）。
