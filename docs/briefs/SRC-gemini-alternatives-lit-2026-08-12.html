solar_backdating：替代 Gemini 的文献简报

聚焦「已知屋顶 footprint → 历史 vintage presence → 安装年」，生产去 Gemini / 自托管 DINOv3 student 的相近工作。DeepSolar-3M 级普查已成熟时，真正空白在这条蒸馏线上。

日期 2026-08-12 篇数 10 核实条目 结论 Gemini→DINOv3 presence 发表系统基本为空
结论 论文 先读 空白 可执行借法

核心结论

最近邻

屋顶自托管定年公开金标准仍是 DeepSolar++；2023–2026 新作多在 utility-scale（GRW / COLD / CCDC），作对照即可。

空白

Gemini 对历史 chip 打 present/absent → DINOv3 student 替换生产 scorer 的完整发表系统未找到。旁路有：Gemini RS caption 教师、航天 VLM 置信度蒸馏、AeroLite。

可借

DINOv3 + ChangeDINO 直接支撑冻结骨干双塔；蒸馏门控抄航天论文的 confidence filter + 迭代 relabel；输入条件化抄 DeepSolar++ 的 HR 参考图。

核实论文 / 系统

必读 · 自托管定年
1. DeepSolar++ (Wang et al., 2022, Joule)
DOI · code

已知位置 + 历史序列 presence；HR 参考条件化的 pseudo-Siamese CNN；约 85.9% 安装年正确率。与你们任务同构，且不依赖托管 VLM——消融基线第一选择。

借法

双塔喂「历史 chip ∥ 最新含 PV 参考」；显式 unusable；再做单调断点。

骨干
5–6. DINOv3 (2025) + ChangeDINO (2025)
DINOv3 · ChangeDINO · code

DINOv3 含卫星变体与蒸馏族；ChangeDINO 用冻结 DINOv3 做建筑变化检测。把「建筑变化」换成「屋顶 PV 出现」即可原型化，推理侧可完全去掉 Gemini。

借法

冻结 DINOv3-SAT + 小头；参考帧 vs 历史帧 Siamese；面积/置信阈值对齐稳定 present。

蒸馏配方
8. Annotation-Free Spacecraft Detection… VLM Distillation (Hicsonmez et al., 2026)
arXiv

VLM 伪标 → 置信度清洗 → 蒸馏轻量学生 → 迭代 relabel。领域是航天器，但是最贴近你们「无独立 GT + fidelity-gated」的配方。

借法

只训高置信 Gemini 子集；TTA 稳健伪标；报告相对教师一致率，而非硬编独立日期 accuracy。

Gemini 教师先例
7. A Recipe for Improving RS VLM Zero Shot… (Barzilai et al., 2025, Google)
arXiv

用 Gemini 1.5 Pro 大规模生成 RS caption 伪监督再训 VLM，并探索蒸馏到定位。证明 Gemini→RS 伪监督可行，但还不是 PV presence/安装年。

对照 · utility
2–4. Global Renewables Watch (2025) · Back in time / reverse-COLD (2025) · Chen et al. China CCDC (2024)
GRW · COLD · RSE

业界主流场站定年完全自托管（分割 + 首次出现 / 光谱突变），不用 GPT/Gemini。分辨率与目标尺寸不覆盖屋顶——Related Work 里写清尺度对照即可。

动机论据
9. AeroLite (2025) · 10. SatMAE / Scale-MAE / DOFA / Prithvi
AeroLite · Scale-MAE 尤其贴 GSD 漂移

AeroLite：API 打标 → 自托管小模型（成本/可部署）。基础模型簇提供无 VLM 骨干选项；屋顶亚米级优先 DINOv3-SAT / Scale-MAE。

最值得读

  1. DeepSolar++ — 屋顶定年金标准 / 消融对照
  2. ChangeDINO + DINOv3 — student 原型骨架
  3. 航天 VLM 蒸馏 (2026) — fidelity / 迭代蒸馏配方
  4. Barzilai Gemini-RS — Gemini 当 RS 教师的先例
  5. Global Renewables Watch — 自托管首次出现工程范本（对照）

Niche 是否为空？

基本为空——这本身有发表价值。 已有 DeepSolar++（自托管屋顶定年）和 VLM→student（航天/caption），缺的是「已知屋顶多边形 + 历史 chip + Gemini 教师 → DINOv3 presence 学生 → 去掉托管 API」的可复现管线。Related Work 可诚实写：任务继承 DeepSolar++，蒸馏借鉴航天/RS-VLM 伪监督，骨干用 DINOv3-SAT，动机是成本 / 可复现 / API 版本漂移。
已有DeepSolar++；Gemini RS caption；航天 VLM 蒸馏；utility 首次出现
仍缺Gemini 作生产级 rooftop presence scorer 的发表系统；Gemini→DINOv3 安装年蒸馏专论；GEHI 稀疏 vintage 的 location-conditioned 配方

可执行借法

  1. 教师数据：Gemini 继续打 present/absent/unusable，只留高置信 / 多视角一致样本。
  2. 学生输入：历史 chip ∥ 最新确认含 PV 参考 ∥ 可选 polygon mask。
  3. 骨干：冻结 DINOv3-SAT（或 ChangeDINO 双塔）+ 小分类头；备选 Scale-MAE。
  4. 时间推断：概率序列 → 单调断点；稳定 present 用面积/置信阈值。
  5. 评估：相对 Gemini 一致率、高置信人工抽检、与 DeepSolar++ 伪 Siamese 的成本–误差 Pareto——无独立 GT 时不要硬报「日期 accuracy」。
相对 DeepSolar-3M：他们把 ViT 普查做厚；你们可以把叙事收成「成熟 census 上游 + 可复现自托管 backdating」，把 Gemini 明确降级为 Phase-0 教师而非生产依赖。
